# A/B-тестирование: баннеры vs пуш-уведомления

Дипломный проект — оценка эффективности двух каналов маркетинговой коммуникации в мобильном приложении розничной сети: баннеры (контрольная группа) против пуш-уведомлений (тестовая группа).

> ⚠️ **О данных.** Исходный датасет содержит данные о реальных клиентах и платежах компании и не публикуется в репозитории по соображениям конфиденциальности. Ноутбук приведён с уже сохранёнными результатами выполнения — графики и таблицы внутри являются фактическим выводом кода на реальных данных, поэтому его можно открывать и просматривать как есть, без повторного запуска.

## Задача

Определить, какой канал уведомления клиентов о скидках и акциях эффективнее по конверсии, среднему чеку и ARPU — и обосновать выбор статистически.

## Данные

- Таблица платежей — 37 989 строк
- Таблица клиентов — 55 605 строк
- Справочник регионов — 66 строк

## Гипотезы

| № | Гипотеза |
|---|----------|
| H1 | Пуш-уведомления увеличивают конверсию клиентов в покупателей |
| H2 | Пуш-уведомления увеличивают средний чек |
| H3 | Пуш-уведомления увеличивают ARPU |
| H4 | Эффективность пуш-уведомлений различается по городам |

## Что сделано

1. **Подготовка данных** — импорт, проверка качества, обработка пропусков, объединение таблиц (SQL: JOIN, агрегации).
2. **Проверка корректности эксперимента** — случайность разбиения на группы, отсутствие пересечений, корректность временных рамок, расчёт минимального размера выборки (MDE = 5%, alpha = 0.05, power = 0.8).
3. **Статистические тесты** — t-test и Mann-Whitney U test для сравнения групп.
4. **Сегментный анализ** — разбивка результата по городам и по 1 430 отдельным торговым точкам с классификацией на успешные / нейтральные / отрицательные (SUCCESS — 323, PARTIAL — 178, FAIL — 929).
5. **Визуализация** — распределения, сравнение групп, экспорт итогового отчёта в Excel с цветовой разметкой по категориям.

## Результат

- Пуш-уведомления увеличили конверсию на **5.5 п.п.** (p-value < 0.05)
- Средний чек вырос на **382–514 ₽** в Москве и Санкт-Петербурге
- Дополнительная выручка в топ-городах: **+2.1–2.3 млн ₽**
- Рекомендация: внедрять пуши точечно — в городах и на точках с подтверждённой эффективностью, а не повсеместно (учитывая долю FAIL-точек)
